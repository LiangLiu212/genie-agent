## One-line takeaway
Proof-of-concept that an LLM reads an ATLAS paper (+refs) and generates the analysis code to reproduce it; confirms our core premises (execution success != correctness; non-determinism must be bounded; human-in-the-loop not autonomous) while leaving our exact niche — provenance/replay for LLM-ORCHESTRATED workflows — open.

## System (two LangGraph stages, LangChain + vLLM)
1. **Selection extraction:** Planner -> Loader (PDF->Markdown via `marker`, maps in-text cites to arXiv IDs) -> Reader (Bulk = full text at once; Chunk = sequential segments for small-context models) -> Merger. Iterates over cited ATLAS papers (cuts are delegated to references). Output: structured JSON, each cut = `content` + `comments` + `references` (arXiv IDs) — a verifiable human-readable intermediate.
2. **Code generation:** Planner -> Generator -> Executor (isolated **Singularity container** with ROOT/numpy/uproot) -> Validator (dual-checks code RUNS and implements the intended cut), loop until validated.

## Benchmark & results
- ATLAS **H->ZZ*->4l**, 2015-16 DAOD_PHYSLITE Open Data; ground truth = **27 curated cuts**; manual reproduction baseline.
- Models: Qwen3 4B/30B/235B, Qwen3-Coder 30B/80B, GPT-OSS-120B; Gemini 2.5 Flash/Flash-Lite baselines. Each run **10x**; LLM-judge (median of 6) scores extraction.
- **Step 1:** >=30B models recover most of 27; Qwen3-235B & Gemini 2.5 Flash hit all 27 in some runs; 4B poor. Heavy run-to-run variance; hallucinations (contradictory cuts) never eliminated. Chunk mode: more cuts for small model but failure rate 0/10 -> 7/10 (more LLM calls = more invalid outputs).
- **Step 2** (event-level vs baseline, 1000 events, 235 selected): Qwen3-Coder-Next-80B **3/10** exact, GPT-OSS-120B **2/10**, Qwen3-Coder-30B **0/10**; rest Not Matched or Execution Failed.

## Money quotes (directly support our thesis)
- "execution success is not a proxy for physical correctness" — same class as our empty-spline-at-rc-0 trap; code runs but selection is wrong.
- LLMs "promising as human-in-the-loop tools for reproducibility support... not yet reliable as fully autonomous agents."
- "successful reproduction suggests sufficient documentation, while failure may indicate missing or ambiguous descriptions" -> use the system as a pre-publication doc-quality check (mirrors our skills/wiki institutional-knowledge idea).

## Determinism / provenance stance
Confronts non-determinism by running 10x and reporting the spread (same as Angermeir 2510.25506 and as us — bound it, don't prompt it away). Sandboxes in a versioned Singularity container. Does NOT address run provenance, seeds, env hashing, or a replay-without-LLM ledger.
