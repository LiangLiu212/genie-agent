## One-line takeaway
Empirical proof that LLM-centric research is largely irreproducible today, and that artifact badges do not fix it — the motivating evidence base for the replay-without-LLM discipline (see [[project-goal-reproducible-agentic-workflow]]).

## What they did
Meta-reproducibility study. Funnel: 425 ICSE 2024 papers -> 78 used LLMs -> **85** LLM-centric articles (ICSE + ASE 2024) -> **69** used OpenAI -> **18** had complete+executable artifacts -> **5** "fit for reproduction." Each of the 5 was containerised and run up to **30 repetitions** (total cost capped at **$500**); reproducibility judged by **Bayesian bootstrap** (10,000 draws, 95% interval — reported value inside interval = "likely" reproducible).

## Headline results (most citable)
- **Of 69 OpenAI studies, only 5 were fit for reproduction. Of those 5, NONE fully reproduced — 2 partial, 3 not reproducible.**
- **ACM artifact badges do not predict reproducibility:** ~1 year post-evaluation, *half* the "Artifacts Evaluated – Reusable v1.1" papers no longer met the badge's own requirements. A badge is not a reproducibility guarantee.
- Under-reporting of determinism knobs: temperature reported by **29/85**; top-p/top-k by **14/85**; context-window handling by **22/85**; prompts by **50/85**. **8/85** named only "ChatGPT"/"LLM"; **10/18** fit-for-repro didn't state the minor model version.

## Factors impeding reproducibility (their Table 2)
General SE issues (dominant): incomplete/missing artifacts (>2/3 of 85 lacked usable artifacts), unspecified dependency versions, general code issues (unassigned vars, **hardcoded paths**), incomplete documentation, non-executable artifacts, lacking error handling, deprecated external API endpoints.
The ONE commercial-LLM-specific factor: **model deprecation / version drift** (`code-davinci-002`, `text-davinci-003` deprecated mid-study; minor versions like `gpt-4o-2024-05-13` unstated). OpenAI's "pinned model is stable" claim is noted as unproven in practice.

## Definitions (ACM; adopt verbatim)
- **Reproducibility:** different team, *same* procedure/system/artifacts -> same result.
- **Replicability:** different team, *independently developed* artifacts -> same result.
(They use the terms interchangeably given the grey area; we should keep the distinction.)

## Recommendations
Mandatory full-artifact disclosure incl. a **Software Bill of Materials**; report exact minor model version + temperature + top-p/top-k + context-window handling + full prompts; venues make disclosure mandatory (not incentivised) and **rethink badge criteria**; a containerised on-demand reproduction framework; funders reward long-term accessibility and don't exempt LLM studies from normal rigor.

## How this maps onto OUR design (the framing for our paper)
Their impeding factors map almost 1:1 onto defenses our design has/plans — use this table:

| Their impeding factor | Our structural defense |
|---|---|
| Unspecified model/minor version | runlog records resolved tune + installation (+ planned `genie_bin_sha256`) |
| Temperature/top-p/**seed** not reported | **seed-materialization** fix: log concrete seed into argv + `inputs.seed` |

## Positioning for our paper
- **Primary motivating citation:** open with their 5/69, 0/5, badges-don't-help result so we never have to argue the problem matters.
- **The gap we fill:** their unit is a *static SE benchmark* (prompt -> metric). Ours is an **LLM that ORCHESTRATES a multi-step scientific workflow** (chooses commands, sequences tools, submits grid jobs); reproducibility unit = the **physics artifact**, and the agent's decisions are part of the process. Frame our contribution as *extending reproducibility discipline from single-shot LLM benchmarks to LLM-orchestrated scientific workflows.*
- **Method to reuse for our Leg-B replay audit:** their **30-repetition + Bayesian-bootstrap 95%-interval** protocol — a peer-reviewed methodology to cite rather than invent.
- **Supports our stance vs the Medium "cognitive anchoring" piece:** they treat LLM non-determinism as irreducible, to be documented+bounded (report temp, run 30x, bootstrap) — NOT prompted away. Same provenance-layer position, peer-reviewed.
