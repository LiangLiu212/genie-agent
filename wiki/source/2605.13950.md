# Collider-Bench: Benchmarking AI Agents with Particle Physics Analysis Reproduction

Faroughy, Palacios Schweitzer, Pang, Mishra-Sharma, Shih (Rutgers NHETC / Boston
University) — **not an experimental collaboration**; NeurIPS 2026 preprint
(2605.13950).

> [!warning] Scope
> This is an **ML/agent-benchmark paper, not a neutrino- or electron-nucleus
> cross-section measurement** — no beam, detector, unfolding, or systematics of
> its own. It was ingested on explicit human instruction as **methodology prior
> art** for agent-driven analysis workflows (this repo's reproducible-agentic-
> GENIE project). It feeds only `concept/` methodology pages; no
> experiment/target/channel/model physics page cites it. Prune on request.

**Scope.** Introduces Collider-Bench: 10 `Simulation` tasks (plus a secondary
`Shape` suite) in which autonomous LLM coding agents must reproduce (recast)
published CMS SUSY searches at √s = 13 TeV, L_int = 35.9 fb⁻¹, given only the
paper and an open toolchain (MadGraph5_aMC@NLO → Pythia 8.313 → Delphes 3.5.0,
Prospino 2.1) in a containerized sandbox (2605.13950). Six off-the-shelf agents
are scored on binned signal yields against hidden references, with an LLM-judge
provenance audit. Headline: "on average no agent reliably beats the
physicist-in-the-loop solution" (2605.13950).
