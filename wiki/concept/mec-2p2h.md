# 2p2h / Meson-exchange currents (MEC)

Two-particle–two-hole excitations: the neutrino couples to a correlated nucleon
pair (often via meson-exchange currents), ejecting two nucleons. 2p2h has no
pion in the final state, so it is part of the **CCQE-like** signal ([[ccqe]])
and a key contributor to the [[transverse-kinematic-imbalance]] distributions
alongside [[fsi]] (2503.15047).

## Modeling (2503.15047)

In MINERvA's central [[genie]] "MINERvA tune" (2503.15047):

- 2p2h uses the **IFIC Valencia** model, simulated only for three-momentum
  transfer q₃ < 1.2 GeV/c (2503.15047).
- It is **empirically enhanced** in specific (energy-transfer, q₃) regions by
  fits to MINERvA low-energy data — the data-driven part of the tune
  (2503.15047).

The companion muon-kinematics analysis (2301.02272) quantifies the same
empirical enhancement: the MnvGENIEv1 modification **increases the integrated
2p2h interaction rate by 49%**, applied as the same fractional increase per
proton–neutron pair for all nuclei (2301.02272). See [[genie]].

Along with Δ-resonance-then-pion-absorption, 2p2h is explicitly included in the
CCQE-like signal definition (2503.15047, 2301.02272).
