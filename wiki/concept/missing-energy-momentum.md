# Missing energy and missing momentum

The two kinematic variables that parametrize the nuclear [[spectral-function]]
in (e,e'p) ([[em-qe]]) knockout (nucl-ex/0303011):

- **Missing energy:** E_m = ω − T_p′ − T_{A−1} (nucl-ex/0303011).
- **Missing momentum:** p⃗_m = p⃗_p′ − q⃗ (nucl-ex/0303011).

## Integration windows / region definitions (nucl-ex/0303011)

| Variable | Region / window | Value |
|---|---|---|
| p_m (spectral functions) | full integration window | \|p_m\| < 300 MeV/c |
| E_m (spectral functions / transparency) | full integration window | E_m ≤ 80 MeV |
| p_m (L–T separation) | restricted window | \|p_m\| < 80 MeV/c |
| E_m (carbon p-shell) | shell window | 10 < E_m < 25 MeV |
| E_m (carbon s-shell) | shell window | 30 < E_m < 50 MeV |
| E_m (Fe, Au momentum dist.) | shell window | 0 < E_m < 80 MeV |

The L–T separations are restricted to |p_m| < 80 MeV/c to suppress the W_LT and
W_TT interference terms (nucl-ex/0303011). See
[[longitudinal-transverse-separation]]. Source: [[source/nucl-ex_0303011]].
